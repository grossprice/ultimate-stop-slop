# Structures to avoid

## Binary contrasts

These create false drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliché |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "X rather than Y" | The same telegraphed reversal wearing a different word |
| "Y, not X" as an appositive | The same move with a comma |

**Instead:** State Y directly. "The problem is Y." "Y matters here." Drop the negation.

"Instead of" reporting what happened is fine: "The answer named a competitor instead of you"
is a fact, not a setup.

## Negative listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Instead:** State Z. The reader does not need the runway.

## Selling by refusal

A section whose subject is what the product will not do, will not promise or does not
measure. A page listing its own refusals argues the reader into doubts they did not arrive
with.

| Pattern | Problem |
|---------|---------|
| "What we will not do" | The heading is a list of refusals |
| "Things we do not do" | Same |
| "No promise about [X]" | Raises the doubt it claims to settle |
| "What this does not measure" | Same, about scope |

**Instead:** State what the product does. Screenshots and real records carry the honesty.

## Reader homework

Telling the reader they have to do something. The reader does not have to do anything; the
product does it for them.

| Pattern | Fix |
|---------|-----|
| "You have to review each report first" | "Each report arrives with its sources." |
| "You need to connect an account" | "Connect an account" as a button, or "We import from your account." |
| "You must confirm your email" | "We sent a link to confirm your email." |

**Instead:** Write the step as something we do, or as something that happens.

## Possessive flips

Ownership drama standing in for a plain verb. Nothing is being said about who does what.

| Pattern | Problem |
|---------|---------|
| "N is yours." | Announces possession instead of naming an action |
| "Z is theirs." | Same, pointed outward |
| "The list is yours" | Who writes it? Say "You write the list" or "We build it from your page" |
| "The pages are yours to keep" | Keeping is not the point. Say what they do |

**Instead:** Name the verb. Somebody writes, edits, keeps or ships the thing.

## Standalone facts

A fact with no consequence attached is half a thought. The reader finishes it with "and what?"

| Pattern | Problem |
|---------|---------|
| "Most buyers compare three vendors." | True, and so what? |
| "Prices change every quarter." | Same. The fact is the setup, not the point |

A heading that states a fact resolves it in the same breath. The fact sets up; the question or
the consequence it creates is the actual heading.

> "Most buyers compare three vendors." is half a thought.
> "Most buyers compare three vendors. Are you on the list?" is the heading.

This is the one place a question heading belongs: as the second half of a fact.

**Instead:** Put both halves in. If the second half does not exist, the fact was not worth a
heading.

## Question-fragment headings

A heading phrased as a question that the content below already answers. It sounds generated.

| Avoid | Use instead |
|-------|-------------|
| "Which campaigns worked" | "Campaign results" |
| "Did anything move" | "Trend" |
| "Where your money goes" | "Spending" |

**Instead:** Name what is under the heading. If a chart answers the question, the heading does
not need to ask it.

## Vague pronouns

A pronoun or phrase with no clear referent.

| Avoid | Use instead |
|-------|-------------|
| "Where you are not showing up" | Name the thing: "Missing pages" |
| "This is what matters" | Name what matters |
| "It all comes down to this" | State the thing |

## Dramatic fragmentation

Sentence fragments for emphasis read as manufactured profundity.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Instead:** Complete sentences. Trust content over presentation.

## Rhetorical setups

These announce insight instead of delivering it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| A rhetorical question opening a section | Posturing. The standalone-fact heading above is the exception |

**Instead:** Make the point. Let readers draw conclusions.

## Formulaic constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## False agency

Giving inanimate things human verbs. Complaints don't "become" fixes. Bets don't "live or die."
Decisions don't "emerge." A person does something to make those things happen. AI loves this
because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Bets don't have lifespans. Someone kills the project or ships it. |
| "the decision emerges" | Decisions don't emerge. Someone decides. |
| "the culture shifts" | Cultures don't shift on their own. People change behavior. |
| "the conversation moves toward" | Conversations don't move. Someone steers. |
| "the data tells us" | Data sits there. Someone reads it and draws a conclusion. |
| "the market rewards" | Markets don't reward. Buyers pay for things. |

**Instead:** Name the human. "The team fixed it that week" beats "the complaint becomes a fix."
If no specific person fits, use "you" to put the reader in the seat.

## Servant verbs

Banned outright. Any "You do X and Y obeys" framing, where a product, page, draft, tool or
setting obeys, follows, listens to or defers to the user. It reads like the thing is a slave to
the user, and nobody writing a marketing page talks like that.

| Pattern | Problem |
|---------|---------|
| "the draft obeys your rules" | Software does not obey. The draft reads like a servant |
| "rules the draft follows" | Same |
| "Edit a link and this list follows" | The "You do X and Y obeys" shape |
| "it listens to you" / "it heeds your feedback" | Same deference, other verbs |
| "the agent complies" / "submits to your review" | Same |
| "does what you say" / "does as it's told" / "takes orders" / "at your command" | Same, as idioms |
| "respects your settings" / "honors your preferences" | Deference dressed up as politeness |
| "answers to you" | Same |

**Instead:** Say what the product does, with a real actor. "We write it in your tone." "We read
the links from the draft on every save, so a link you edit shows up here."

"Follow" also has a time sense ("the steps that follow", "the following") and "answers to" is
also a noun phrase ("the answers to one question"). Those senses are not servant verbs. The
checker warns on every "follow" and does not look for "answers to", so a person judges both.

## Narrator-from-a-distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to..." beats
"Nobody designed this."

## Passive voice

A sentence needs a subject doing something. Passive voice hides the actor and drains energy.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

**Instead:** Find the actor. Put them at the front of the sentence.

## Sentence starters to avoid

| Pattern | Fix |
|---------|-----|
| Statements starting with What, When, Where, Which, Who, Why, How | Restructure. Lead with the subject or the verb |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

Wh- openers become a crutch. "What makes this hard is..." becomes "The constraint is..." or,
better, the specific constraint.

**Exempt:** questions a reader would ask. FAQ entries ("How do I cancel?"), search queries,
form questions and the question half of a standalone-fact heading keep their Wh- word.

## Rhythm patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists | Use two items or one |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends punchily | Vary endings |
| Em dashes | Remove. Use commas, colons or periods. See mechanics.md |
| Staccato fragmentation | Don't stack short punchy sentences |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Word patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, everybody, nobody) | False authority. Use specifics instead of sweeping claims |
| -ly adverbs, intensifiers, softeners, hedges | Empty emphasis. See phrases.md |

"Every" survives in two jobs, because "all" would be wrong or weaker there:

- **A cadence or a scope.** "Every day", "every three days", "every plan". "All days" is not
  English.
- **A promise about each item, one at a time.** "Every number links to the record behind it."
  "All numbers link to records" makes a weaker promise.

In a UI label "every" is a tic. See ui-copy.md.
